Rollout: pilot the agreement first, then let the evidence build
PHASE 1 · CORE PILOTCORE Standard cleaning only, one district, volunteer Taskers. Quality Agreement (1.1–1.5), first-visit check and change approval (3.1–3.2), photo proof and result check (3.3–4.1). Matching uses data beHome holds: ID, jobs, beAcademy modules.
PHASE 2 · BUILD THE EVIDENCE Verified feedback switches on area scores and calibrates time estimates. Deep Cleaning opens once enough Taskers are verified for it. Saved Cleaning Plan with Tasker-first rebooking and a verified backup.
PHASE 3 · PROMISE AT SCALE Publish the ClearClean Recovery Promise to all customers if pilot claim costs hold. Case data feeds beAcademy coaching, and capability matching extends across the city.
